No Cardio

45-minute core and legs workout for two. No cardio. Spoken guidance and timers.

The rules

  • Pick a weight where the last 2 reps feel hard but clean.
  • Start lighter than you think.
  • Sharp or joint pain means stop and use the swap.
  • Ask the attendant to set seat heights.

Turn volume up and switch off silent mode (iPhone side switch) so beeps play. Keep this page open; the screen will stay on.

Warm-up 5 min: mobility only, no bike or treadmill.
Main circuit, 3 sets each, legs and core alternating: leg press, plank, dumbbell Romanian deadlift, dead bug, reverse lunge, Pallof press, leg curl or extension, side plank. Rest 45s between sets.
Him: 10-12 reps. Her: 12-15 reps.
Cool-down 3 min: leg, hip and back stretches.
